# Old Basic Projects

A collection of my early programming projects, learning exercises, and older websites.

Each project is preserved in its own folder, including its original tracked assets and documentation. Open a project folder for its source code and any setup instructions.

These are snapshots of the source repositories, not a combined application. Original commit histories remain in the source repositories. Exact imported commits and file counts are recorded in [SOURCES.json](SOURCES.json).

The original `web-dev-projects` repository contains six Git links rather than embedded project files. Those pointers are preserved as originally stored. `css-card` and `firstwebsmolproject` also have their own complete folders here. Some other pointers refer to repositories removed before this import; their contents are not included in the source snapshot.
